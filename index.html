Modulation Matrix Simulator

Objective: Make a static sound move by routing modulation sources (LFO, Velocity, Mod Wheel) to targets (Pitch, Loudness, Filter Cutoff).

Instructions:

  1. Click Start Simulator.
  2. Understand the difference between Audio Flow (the sound) and Control Flow (what moves the settings).
  3. Complete the 5 sequential missions to recreate classic musical effects: Vibrato, Tremolo, Wah, and Dynamic Velocity.
  4. Use the virtual keyboard button to trigger the sound.

Control Flow: Making a Sound Move

Connect a source (what moves) to a target (what gets changed).
